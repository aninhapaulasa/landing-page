
# 🚀 DevStart — Landing Page

Landing Page moderna e responsiva desenvolvida com HTML5 e CSS3, como parte dos projetos práticos do meu portfólio Front-end.

O projeto apresenta a **DevStart**, uma plataforma fictícia de cursos de programação, com foco em organização visual, estrutura semântica e adaptação para diferentes dispositivos.

## 🎯 Objetivo

Desenvolver uma Landing Page utilizando HTML e CSS, aplicando conceitos de:

- HTML semântico
- CSS Flexbox
- CSS Grid
- Responsividade com Media Queries
- Organização de layouts
- Estilização de componentes
- Experiência do usuário
- Acessibilidade básica

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries
- Git e GitHub (versionamento)

## ✨ Funcionalidades

- Menu de navegação com links internos
- Seção principal (Hero)
- Botões de chamada para ação (CTA)
- Cards de benefícios
- Seção de apresentação da plataforma
- Rodapé informativo
- Efeitos hover em botões e cards
- Rolagem suave entre seções
- Layout responsivo para desktop, tablet e celular
- Navegação por teclado com foco visível

## 📱 Responsividade

A página foi desenvolvida para se adaptar a diferentes tamanhos de tela.

Foram utilizadas Media Queries para reorganizar os elementos:

- Desktop: layout com múltiplas colunas
- Tablet: adaptação dos espaçamentos e cards
- Celular: elementos organizados verticalmente
- Telas pequenas: ajustes de fontes e botões

## 📂 Estrutura do projeto

```text
landing-page/
├── assets/
│   └── hero.png
├── index.html
├── style.css
└── README.md
```

A pasta assets é utilizada caso o projeto contenha imagens locais.

## 💻 Como executar o projeto

1. Baixe ou clone o repositório.
2. Abra a pasta do projeto no VS Code.
3. Abra o arquivo index.html no navegador.
4. Opcionalmente, utilize a extensão Live Server.

Não é necessário instalar dependências.

## 📚 Aprendizados

Durante o desenvolvimento, pratiquei:

- Organização de páginas com HTML semântico
- Criação de layouts com Flexbox e Grid
- Estilização de botões, cards e seções
- Utilização de cores, espaçamentos e tipografia
- Desenvolvimento de interfaces responsivas
- Testes em diferentes tamanhos de tela
- Boas práticas básicas de acessibilidade
- Organização e manutenção de código CSS
